# Docker Container Collector

![PyPI version](https://img.shields.io/pypi/v/docker-container-collector.svg)
[![Documentation Status](https://readthedocs.org/projects/docker-container-collector/badge/?version=latest)](https://docker-container-collector.readthedocs.io/en/latest/?version=latest)

The Docker Container Collector uses the Thunderstorm Collector to scan Docker containers.

* PyPI package: https://pypi.org/project/docker-container-collector/
* Free software: MIT License
* Documentation: https://docker-container-collector.readthedocs.io.

## Run Script 

Run `pip3 install -e .` before running the script the first time on your system.
Then you can start the script by run `docker_container_collector` in the root directory of the subproject.

## Tests

Run `pip3 install -e .[test]` before testing the script the first time on your system.
Then use `pytest` to test the functions of the script.
